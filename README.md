# Spod Buildathon Hall of Fame

Builders selected in the Spod Buildathon.

## Add your entry
1. Fork this repo.
2. Create `rounds/2026/<your-github-username>.md` using the format below.
3. Open a pull request.

## Entry format
**Name:** Your name
**Team:** Team name
**Project:** One-line public description
**Role:** What you built
**Certificate:** Link to your Spod verify page

Share public information only. Don't include confidential project details.
